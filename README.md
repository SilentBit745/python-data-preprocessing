Python for Machine Learning and Data Preprocessing
About the Project
This project demonstrates the basic steps of preparing data for machine learning using Python. A sample student dataset is used to practise data cleaning, missing-value handling, duplicate removal, categorical encoding, normalization, and exploratory data analysis.
Technologies Used

Python
Pandas
NumPy
Scikit-learn
Google Colab

Work Completed

Created and inspected a sample dataset.
Identified missing values.
Removed duplicate records.
Filled missing numerical values using column averages.
Converted categorical gender data into numerical columns.
Normalized numerical features using MinMaxScaler.
Explored the processed data using summary statistics.
Exported the final dataset to a CSV file.

Project Files

Week1_Data_Preprocessing.ipynb — Python code and preprocessing steps.
cleaned_student_data.csv — Processed dataset.

Results
The original dataset contained 6 records. After removing the duplicate record, 5 records remained. Missing numerical values were handled, categorical data was encoded, and selected numerical features were scaled between 0 and 1.
Learning Outcomes
This project provided practical experience with data cleaning, preprocessing, feature transformation, and basic exploratory data analysis using Python libraries.
